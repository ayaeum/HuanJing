# 真实文本理解与候选召回

默认运行使用实际模型 API。简化的是存储和检索规模：保留 SQLite，把当前租户最多 50 个启用的公开画像全部交给模型评分。当前预置画像只有五个，因此暂时使用全量评分，不需要向量数据库或 embedding 服务。

## 处理流程

1. **UNDERSTAND**：模型读取帖子正文及用户填写的媒体描述，返回摘要、交流意图和主题列表。摘要由模型生成，主题不受本地固定词表限制。
2. **MATCH**：第二次模型调用接收原文、分析及公开画像快照，逐一返回相关性、0..1 分数、简短匹配说明及原文证据。
3. **验证与筛选**：检查 JSON 字段、全画像覆盖、ID 白名单、分数范围和证据原文出处。仅保留 relevant=true 且达到阈值的画像，按分数选择候选。分数是模型自评，尚未做概率校准。
4. **发布边界**：保存候选前再次检查帖子版本、任务 epoch、分身启用状态和画像 epoch。模型只能提供评分，不能改变授权或直接发布。

请求只包含当前租户公开画像，私有记忆不会送入语义模型。帖子、上一阶段分析及画像均作为不可信数据放在 user 消息中；系统提示明确限定任务，返回值仍需程序验证。提示注入样例测试通过，不代表所有攻击都已被覆盖。

实际入口：[semantic.go](../internal/app/semantic.go)、[ai.go](../internal/app/ai.go)。旧词表/hash 实现隔离在 [fixture_matching.go](../internal/app/fixture_matching.go)，仅 `AI_MODE=test_fixture` 可执行；真实模式调用失败时没有规则回退。

## 配置与凭据

| 环境变量 | 用途 |
| --- | --- |
| `AI_MODE` | 默认 `real`；离线工作流测试必须显式指定 `test_fixture` |
| `AI_BASE_URL` | 兼容 API 的基础地址，包含 API 前缀；客户端追加 `/chat/completions` |
| `AI_API_KEY` | 作为 Bearer 凭据发送，只保留在进程配置中 |
| `AI_MODEL` | 网关支持的模型路由名，无源码默认值 |
| `AI_TIMEOUT_SECONDS` | 默认 45，范围 1..120；同时受任务业务截止时间限制 |
| `AI_RELEVANCE_THRESHOLD` | 默认 0.65，范围 >0 且 <=1 |

缺少真实配置时启动失败。服务不会自动读取 `.env`；本地 shell 或部署系统需要将配置注入环境。模板为 [.env.example](../.env.example)，实际 `.env*` 已加入 Git 忽略规则。实际接入点、密钥不写入代码、数据库或测试报告；健康检查只展示运行模式与能力边界。HTTPS 重定向不会自动跟随，避免凭据跨地址转发；回环 HTTP 只用于协议测试。

适配器使用标准 chat messages 和 max_tokens，通过提示要求 JSON，再本地严格解析。当前已验证网关的普通文本生成可用，而其 `response_format=json_object` 参数不兼容，因此客户端没有依赖该参数。模型输出不符合协议时明确失败。

网关返回的模型名称是路由标签，实际请求和 token 响应能证明调用发生，不能独立证明底层模型身份。报告不会把网关模型目录当作身份或能力保证。

## 持久化与未知结果

真实调用记录在 `ai_operations`，模拟决策/评论保留在 `operations`，二者不会混用回执。真实账本保存公开输入快照、请求哈希、模型标签、结果、响应 ID、状态和报告的输入/输出 token；API 只公开脱敏计费元数据。

- 发送前创建 RUNNING 并原子预留一个请求额度。成功响应经校验后持久化，阶段重启可复用同一结果。
- 429/5xx 明确失败进入有上限的重试，每次请求均保守消耗一个额度；这些额度不代表供应商实际货币收费。401 等配置/权限错误和无效结构化响应停止，不自动复调。
- 超时、断连、崩溃遗留 RUNNING 转为 UNKNOWN，保留额度预留，普通 retry 拒绝重新请求。供应商是否执行及收费仍未知。
- 用户可显式 `resolve-ai`，将未知请求放弃并按消耗一个额度结算；此操作不会生成模型结果、退款或重新调用。之后再显式 retry 才会创建新收费尝试。取消/删除后也可处理剩余元数据，任务保持终态。
- 已知响应缺少 usage 时标为 `usage_reported=false`，界面显示“未报告”，不会把缺失数据当成零 token。

供应商不提供查询回执接口时，本实现无法恢复丢失的模型响应，也无法确认账单。任务本地恢复与供应商请求恰好一次是不同保证。发送前已持久化但尚未发出的极窄崩溃窗口也保守归为 UNKNOWN。

## 仍然模拟的部分

内容审核仍为词表；原始图片/音频/视频没有视觉理解、OCR、ASR；分身动作决策仍为确定性规则，评论仍为模板。SQLite 发布、outbox、幂等、版本与撤权校验是真实本地执行。真实模型评分样例集较小，不能据此宣称通用推荐质量或真实供应商容量；原来的 Mock 压测报告也不适用于当前真实模型延迟和吞吐。
